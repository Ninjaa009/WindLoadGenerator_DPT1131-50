# บทที่ 3 การคำนวณแรงลม (Wind Load) ตาม มยผ. 1311-50

> บทนี้อธิบายวิธีคำนวณแรงลมสถิตเทียบเท่าสำหรับ **อาคารเตี้ย (low-rise building)** ตามมาตรฐาน มยผ. 1311-50
> โดยใช้ค่าและสูตรชุดเดียวกับโปรแกรม [`wind_load.py`](../wind_load.py) ในรีโปนี้
> พร้อมตัวอย่างคำนวณจริงทีละขั้น ผลลัพธ์ตรงกับที่โปรแกรมพิมพ์ออกมา

---

## 3.1 ขอบเขตและสมมติฐาน

- ใช้วิธีสถิตเทียบเท่า (Static / Envelope Procedure) สำหรับอาคารเตี้ย
- หน่วยแรงลมคิดเป็น N/m² แล้วหารด้วย g = 9.81 เพื่อแสดงเป็น kg/m²
- เครื่องหมาย: ค่าบวก (+) คือ **แรงกด** เข้าหาผิว ค่าลบ (−) คือ **แรงดูด/ยก** ออกจากผิว
- มุมหลังคาเลือกเป็นช่วง (bin) ตามตาราง ยังไม่ interpolate ระหว่างช่วง

## 3.3 หน่วยแรงลมอ้างอิง q

ความเร็วลมอ้างอิงคาบ 50 ปีของแต่ละกลุ่มพื้นที่:

| กลุ่ม | V₅₀ (m/s) | T_F |
|---|---|---|
| 1 | 25 | 1.0 |
| 2 | 27 | 1.0 |
| 3 | 29 | 1.0 |
| 4A | 25 | 1.2 |
| 4B | 25 | 1.08 |

```
V̄ = V₅₀            (ทั่วไป)
V̄ = T_F · V₅₀      (รวมผลไต้ฝุ่น — บังคับใช้กับอาคารสำคัญสูงมาก)
q = ½ · ρ · V̄²     โดย ρ = 1.25 kg/m³
```

**ตัวอย่าง**

```
V̄ = V₅₀ = 25.00 m/s
q = 0.5 × 1.25 × 25.00² = 390.6 N/m² = 39.82 kg/m²
```

## 3.4 ความสูงอ้างอิง h และค่าประกอบสภาพภูมิประเทศ Cₑ

```
θ = atan((H_ridge − H_eave) / (B/2))
h = (H_eave + H_ridge) / 2    แต่ไม่น้อยกว่า 6 m
```

| Exposure | สภาพ | สูตร Cₑ | ขอบเขต |
|---|---|---|---|
| A | เมืองใหญ่หนาแน่น / ชายฝั่งคลื่นลมแรง | `(z/10)^0.28` | 1.0 – 2.5 |
| B | ชานเมือง / ศูนย์กลางเมืองขนาดเล็ก | `0.5·(z/12.7)^0.5` | 0.5 – 2.5 |
| C | ศูนย์กลางเมืองใหญ่ ตึกสูงหนาแน่น | `0.4·(z/30)^0.72` | 0.4 – 2.5 |

**ตัวอย่าง**

```
θ  = atan((7.5 − 6.0) / (20/2)) = 8.53°
h  = (6.0 + 7.5) / 2 = 6.75 m  ≥ 6 m  → ใช้ h = 6.75 m
Cₑ = 0.5 × (6.75/12.7)^0.5 = 0.365  < 0.5  → ใช้ Cₑ = 0.500
```

> **ข้อสังเกต** θ ที่คำนวณได้ (8.53°) เกินช่วง 0°–5° ที่เลือกไว้
> ในงานจริงควรเลือกช่วงมุมที่ครอบคลุม หรือเทียบผลทั้งสองช่วง (0°–5° และ 20°) แล้วใช้ค่าที่วิกฤตกว่า

## 3.5 ค่าประกอบการกระโชกและค่าประกอบความสำคัญ

- Cg = 2.0 (ภายนอก — รวมอยู่ในตาราง Cg·Cp แล้ว ไม่ต้องคูณซ้ำ)
- Cgi = 2.0 (ภายใน)

| ประเภทความสำคัญ | ตัวอย่างอาคาร | Iw ด้านกำลัง | Iw ด้านใช้งาน |
|---|---|---|---|
| น้อย | เกษตร / ชั่วคราว | 0.8 | 0.75 |
| ปกติ | อาคารทั่วไป | 1.0 | 0.75 |
| มาก | ชุมนุมคน / โรงเรียน | 1.15 | 0.75 |
| สูงมาก | โรงพยาบาล / สถานีดับเพลิง | 1.15 | 0.75 |

**ตัวอย่าง** อาคารปกติ ด้านกำลัง → Iw = 1.00

## 3.6 ระยะโซนขอบ z และ y

```
z = min(0.10 · ด้านแคบ, 0.40 · h)   แต่ไม่น้อยกว่า max(0.04 · ด้านแคบ, 1 m)
y = max(6 m, 2z)
```

**ตัวอย่าง** ด้านแคบ = min(20, 40) = 20 m

```
z = min(0.10 × 20, 0.40 × 6.75) = min(2.00, 2.70) = 2.00 m
    ตรวจค่าต่ำสุด max(0.04 × 20, 1) = 1.00 m  → ใช้ z = 2.00 m
y = max(6, 2 × 2.00) = 6.00 m
```

## 3.7 หน่วยแรงลมภายใน pᵢ

```
pᵢ = Iw · q · Cₑ · Cgi · Cpi
```

| กรณี | Cpi | ลักษณะช่องเปิด |
|---|---|---|
| 1 | −0.15 หรือ 0.0 | ช่องเปิดรวม < 0.1% ของผิวทั้งหมด |
| 2 | −0.45 หรือ 0.3 | รั่วซึมไม่สม่ำเสมอ ปิดสนิทได้เมื่อมีพายุ |
| 3 | −0.7 หรือ 0.7 | ช่องเปิดขนาดใหญ่ ต้านพายุไม่ได้ |

**ตัวอย่าง** (กรณีที่ 3)

```
pᵢ(+) = 1.00 × 390.6 × 0.500 × 2.0 × (+0.7) = +273.4 N/m² = +27.87 kg/m²
pᵢ(−) = 1.00 × 390.6 × 0.500 × 2.0 × (−0.7) = −273.4 N/m² = −27.87 kg/m²
```

## 3.8 หน่วยแรงลมภายนอก p และแรงสุทธิ p_net

```
p     = Iw · q · Cₑ · (Cg·Cp)
p_net = p − pᵢ
```

**ตัวอย่าง** ตัวคูณร่วม

```
Iw · q · Cₑ = 1.00 × 390.6 × 0.500 = 195.3 N/m² = 19.91 kg/m²
→ p = 19.91 × (Cg·Cp)  kg/m²
```

## 3.9 กรณีน้ำหนักบรรทุก (Load Case)

| LC | ทิศลม | ความดันภายใน | ตาราง |
|---|---|---|---|
| LC1 | ตั้งฉากสันหลังคา | บวก | กรณีที่ 1 — 8 โซน |
| LC2 | ตั้งฉากสันหลังคา | ลบ | กรณีที่ 1 — 8 โซน |
| LC3 | ขนานสันหลังคา | บวก | กรณีที่ 2 — 12 โซน |
| LC4 | ขนานสันหลังคา | ลบ | กรณีที่ 2 — 12 โซน |

แต่ละ LC ป้อนเข้าโปรแกรมวิเคราะห์โครงสร้างแยกกันเป็นคนละ load case
การหาค่าวิกฤตจะเทียบเฉพาะ LC ของทิศลมเดียวกัน (LC1 กับ LC2, LC3 กับ LC4)
เพื่อให้แรงทุกโซนในชุดนั้นเกิดขึ้นพร้อมกันได้จริง
